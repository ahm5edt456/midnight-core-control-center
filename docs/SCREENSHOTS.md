# Screenshot guide

The `interface-concept.png` in this package is an illustration, **not** a screenshot from the live application.

To make the README fully authentic, open the Control Center on Fedora GNOME and capture:

- Overview: `docs/images/overview.png`
- Appearance: `docs/images/appearance.png`
- Developer Tools: `docs/images/developer-tools.png`

Insert the Markdown snippet from the README under **Adding real screenshots** and remove the concept image if preferred.
Before uploading, ensure private usernames, IP addresses, local paths, container names, or tokens are not visible.
